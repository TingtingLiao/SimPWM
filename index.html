Insights

Video world models lose the object; simulators alone look synthetic. Using the simulator as a proxy gets both right.

GTreference

Real robot lifts the rope, given the first frame and its recorded actions.

Video world modele.g. Ctrl-World
  • Object follows the actionsrope dissolves
  • Looks real
Simulator onlye.g. Agentic Real2Sim
  • Object follows the actionsrope not carried
  • Looks real
SimPWM (ours)
  • Object follows the actionsrope carried
  • Looks real

Method

Lift the first frame into points, move them with a rule-based simulator, and render the proxy into video.
